# Apps-and-Websites

This repository holds more than one project. Each project lives in its own folder with its own `CLAUDE.md`.

| Project | Folder | Start here |
|---|---|---|
| Coach Mia (dating and relationship coaching app for men: iOS, Android, web) | `coach-mia/` | `coach-mia/CLAUDE.md` |

Rules for any AI working in this repo:

1. Before touching a project, read that project's `CLAUDE.md` in full. It is the operating manual.
2. Never let one project's code, config or dependencies leak into another project's folder.
3. Do not add files at the repo root except this file, `AGENTS.md`, `README.md` and shared tooling that every project has agreed to.
